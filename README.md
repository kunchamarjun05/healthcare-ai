An AI-powered multi-disease prediction system that uses machine learning to predict the likelihood of **Diabetes**, **Heart Disease**, and **Parkinson's Disease** based on patient health parameters.

---

## ✨ Features

- 🔬 **Multi-Disease Prediction** — Supports Diabetes, Heart Disease & Parkinson's
- 🤖 **ML Models** — Trained using SVM, Random Forest & XGBoost
- 📊 **Interactive Dashboard** — Beautiful Streamlit UI with real-time predictions
- 📈 **Data Visualization** — Charts and graphs for health parameter analysis
- ⚡ **Instant Results** — Get prediction results in seconds
- 🎯 **High Accuracy** — Models trained and optimized for best performance

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/kunchamarjun05/healthcare-ai.git
cd healthcare-ai

# Install dependencies
pip install -r requirements.txt

# Run the app
streamlit run app.py
```

```

```

## 🧠 How It Works

1. **Select Disease** — Choose which disease to predict
2. **Enter Parameters** — Input health metrics (blood pressure, glucose, etc.)
3. **Get Prediction** — AI model analyzes data and returns prediction
4. **View Analysis** — See detailed charts and confidence scores
